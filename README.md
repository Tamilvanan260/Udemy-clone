# Udemy Homepage Clone

A static, responsive clone of the Udemy homepage built with semantic HTML5 and CSS3 (Flexbox). No frameworks, no JavaScript.

**Live Demo:**https://tamilvanan260.github.io/Udemy-clone/

## Features

- Navbar with logo, search bar, Courses, My Learning and cart / notification / profile icons
- Scrollable category menu bar (Development, Business, IT & Software, AI, Finance, Design, Marketing and more)
- Hero banner with a learning message
- Recommended Courses section with course cards (image, title, instructor, rating, price)
- Recommended Topics section with topic chips
- Popular Courses section showing courses by rating and reviews
- Footer with link columns and copyright
- Flexible layout using `flex-wrap`, so cards adjust to different screen sizes

## Tech Stack

- HTML5
- CSS3 (Flexbox, hover effects)
- Google Fonts (Gabarito)
- Font Awesome icons

## Getting Started

```bash
git clone https://github.com/Tamilvanan260/udemy-clone.git
cd udemy-clone
```

Open `index.html` in your browser. An internet connection is needed to load the font and icons.
